# WebTodo

A lightweight, no-build ToDo web app. Add, complete, edit, and delete tasks —
all saved in your browser via `localStorage`.

## Features

- Add tasks with one click or the Enter key
- Mark tasks done with a satisfying toggle
- Double-click a task to edit it inline
- Filter by **All / Active / Completed**
- Live count of active tasks
- Clear completed tasks in one click
- Tasks persist across visits (localStorage)
- Clean, responsive design — works on mobile and desktop

## Run it

Just open `index.html` in any browser. No dependencies, no build step.

Or serve it locally:

```bash
npx serve .
```

## Tech

Plain HTML, CSS, and JavaScript. Zero dependencies.
